# Six-Month Learning Roadmap

The roadmap below is based on the skills that appeared repeatedly in the researched Full-Stack Developer job listings.

## Month 1 – Frontend Foundation

### Focus
React and JavaScript

### Topics
- Strengthen JavaScript fundamentals
- React components
- Props and state
- React hooks
- Forms and validation
- API calls
- Responsive design
- Build a small React application

### Goal
Become comfortable creating complete frontend interfaces using React.

---

## Month 2 – TypeScript and Advanced Frontend

### Focus
TypeScript and React

### Topics
- TypeScript fundamentals
- Types and interfaces
- Generics
- Type React components and props
- Type API responses
- React hooks with TypeScript
- Next.js fundamentals

### Goal
Build a React and TypeScript application using clean and maintainable code.

---

## Month 3 – Backend Development

### Focus
Node.js and Express

### Topics
- Node.js fundamentals
- Express.js
- REST APIs
- Routing
- Middleware
- Error handling
- Environment variables
- API validation

### Goal
Create a backend API that can communicate with a React frontend.

---

## Month 4 – Databases and Authentication

### Focus
PostgreSQL and secure APIs

### Topics
- SQL
- PostgreSQL
- Database design
- Relationships
- Joins
- CRUD operations
- Prisma or another ORM
- User authentication
- JWT
- Authorization

### Goal
Build a complete application with users, authentication and a relational database.

---

## Month 5 – Testing and Deployment

### Focus
Professional development practices

### Topics
- Unit testing
- Integration testing
- API testing
- Git branching
- Pull requests
- Docker fundamentals
- CI/CD basics
- Deploy a full-stack application

### Goal
Learn how to build, test and deploy applications using professional development practices.

---

## Month 6 – Portfolio and Cloud

### Focus
Production-ready development

### Topics
- AWS fundamentals
- Cloud deployment
- Application security
- Performance improvements
- Documentation
- GitHub repository organization
- Professional README files
- Complete 2–3 portfolio projects
- Technical interview preparation

### Goal
Have a strong full-stack foundation and 2–3 portfolio projects that demonstrate the skills requested by employers.
