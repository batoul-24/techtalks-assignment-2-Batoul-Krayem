## 3. Pattern Analysis

After comparing the five job listings, several technologies and skills appeared repeatedly.

**React / ReactJS** appeared in all five listings, making it one of the most important frontend skills for Full-Stack Development.

**SQL and relational databases** also appeared in all five listings. The specific databases included PostgreSQL, MySQL, and SQL Server. This shows that database knowledge is essential for full-stack developers.

**Node.js** appeared in four out of five listings, showing that backend JavaScript development is highly relevant.

**TypeScript** appeared in four out of five listings. Its repeated use alongside React and Node.js makes it an important technology to prioritize.

**REST APIs** appeared in four out of five listings and are clearly an important part of connecting frontend and backend systems.

**Git / Version Control** appeared in three out of five listings. This shows that employers expect developers to be comfortable with collaborative development, branches, pull requests, and maintaining code repositories.

Other skills appeared less frequently but are still valuable. These include **Next.js, CI/CD, cloud technologies such as AWS, Docker, automated testing, authentication, JWT, Prisma, and other ORMs**.

### Essential Skills

The most important skills based on the listings are:

- React
- Node.js
- TypeScript
- SQL and relational databases
- REST APIs
- Git

These should form the foundation of my learning plan.

### Secondary Skills

The secondary skills include:

These skills should be learned after establishing a strong full-stack foundation.

### What Surprised Me

One thing that surprised me was how often employers mention skills beyond simply writing frontend and backend code. Git, testing, CI/CD, databases, APIs, and deployment are also important.

This shows that employers expect developers to understand the complete software development process rather than only knowing programming languages or frameworks.

Another important observation was the repeated appearance of TypeScript alongside React and Node.js. This makes TypeScript an important skill to prioritize.
