# Portfolio Plan

The following projects are designed to demonstrate the skills that appeared repeatedly in the job listings.

## Project 1 – Full-Stack Task Management Application

### Description

A web application where users can create accounts and manage personal or team tasks.

### Technologies

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- REST API
- JWT authentication
- Git

### Main Features

- User registration and login
- Create, edit and delete tasks
- Task categories
- Task priorities
- User authentication
- Search and filtering
- Responsive interface

### Skills Demonstrated

This project demonstrates frontend development, backend development, database management, REST APIs, authentication and Git.

## Portfolio Goal

By the end of the six-month roadmap, I aim to have 2–3 complete projects on GitHub. Each project should include a clear README, screenshots, technologies used, setup instructions and a description of the main features.

The projects should demonstrate practical skills rather than simply listing technologies on a resume.
